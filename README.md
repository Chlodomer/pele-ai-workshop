# בינה איכותנית — סדנה יישומית (HIGH AI / פל״א)

אתר הסדנה ״עבודה עם סוכני AI במחקר איכותני״, ריטריט פל״א, ספטמבר 2026.

- **התרגיל** — היעד והחומר, בניית סוכן, הפעלה, בדיקה מול המקור, שיפור הפירוש.
- **בונים סוכן** — רשימת בדיקה אינטראקטיבית לכתיבת הוראת עבודה לסוכן.
- **מפת התרגיל** — הצעדים במבט אחד.

כל חומרי התרגול סינתטיים ונועדו לתרגול בלבד. קובץ המקורות: `public/downloads/workshop-exercise.pdf`.

## פיתוח

```
npm install
npm run dev
```

הפריסה ל־GitHub Pages נעשית אוטומטית מ־`main` דרך GitHub Actions.
